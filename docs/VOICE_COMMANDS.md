# Voice Commands Reference

## System Commands
| Command | Description |
|---------|-------------|
| "JARVIS" / "Hey JARVIS" | Wake word |
| "Stop" / "Cancel" | Stop current action/speech |
| "Can you hear me?" | Audio check |
| "What time is it?" | Current time |
| "What's the date?" | Current date |
| "System status" | System health check |
| "Ping" | Connectivity test |

## Voice Control
| Command | Description |
|---------|-------------|
| "Mute" / "Unmute" | Toggle audio |
| "Volume up/down" | Adjust volume |
| "Pause" / "Resume" | Media control |
| "Next track" / "Previous track" | Media navigation |

## Screen & Window
| Command | Description |
|---------|-------------|
| "Take screenshot" | Capture screen |
| "What's on my screen?" | OCR screen content |
| "Click [element]" | Click UI element |
| "Scroll up/down" | Scroll |
| "Switch window" | Alt+Tab |
| "Minimize all" | Show desktop |

## File Operations
| Command | Description |
|---------|-------------|
| "Open [file]" | Open file |
| "Read [file]" | Read file content |
| "List files" | List project files |
| "Recent downloads" | Show recent downloads |
| "Create file [name] with content [text]" | Create file |

## System
| Command | Description |

## Development
| Command | Description |

## Notes & Memory
| Command | Description |
|---------|-------------|

## Remote (iPhone)
| Command | Description |

## Keyboard Shortcuts (Web UI)
| Key | Action |
|-----|--------|
| `M` | Toggle microphone |
| `S` | Open settings |
| `Enter` | Send command |
| `Escape` | Close modal |
