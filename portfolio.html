About

I'm an AI Engineer passionate about building autonomous, privacy-first AI systems that run entirely on local hardware. My work spans LLMs, computer vision, voice AI, and full-stack development — with a focus on systems that respect user privacy and operate without cloud dependencies.

I'm the creator of JARVIS — an autonomous local-first AI computer companion featuring voice interaction, real-time screen understanding, autonomous web research, Git intelligence, and a mobile remote companion. It runs entirely on your hardware using Ollama, with zero cloud dependencies.
